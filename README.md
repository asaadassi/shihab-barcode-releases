# shihab-barcode-releases

Releases of **Barcode by Shihab App** (باركود · ماسح بلوتوث من شهاب آب), Android 9+: turns the phone into a Bluetooth keyboard barcode scanner.

APKs, SHA-256 sums and signatures only. The source code is public at https://github.com/asaadassi/shihab-barcode (GPL-3.0, a modified version of HID Barcode Scanner by Fabi019).
